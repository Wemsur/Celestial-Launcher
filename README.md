# Modrinth App Edit

基于 [Modrinth App](https://github.com/modrinth/modrinth-app) 的修改版，专注于精简功能、优化界面、提升本地化体验。

## 已实现特性

- 离线登录功能与账户管理页面
- 自定义背景图片及背景模糊选项
- 新增「素雅」「古典黑」主题
- 移除右侧栏广告区域及左侧 Modrinth Hosting 按钮
- 实现 Worlds 界面，支持将其设为默认启动页

## 未来规划

- 完成实例背景功能
- 进一步界面优化
- 中文搜索等本地化支持

## 优势

- **界面始终贴合原版设计**：统一的UI设计，在自定义背景时仍然保持左上圆角，新添加界面使用与原 Modrinth App 完全贴合的设计，以提供统一的使用体验。
- **数据库结构不变**：不修改底层数据库 schema，可随时切换回原版或第三方 Modrinth App 分支
- **持续更新**：积极跟进上游变更，修复兼容性问题

> 欢迎提交 Issues 反馈问题或提出建议。
> 由于开发者学业繁忙，更新节奏可能较慢，敬请谅解。

## 注意事项

请勿从较新的 Modrinth App 官方版本降级到本修改版的旧版本，可能导致数据不一致或其他问题。
