# 一个Modrinth App的修改版

主要专注于删除modrinthapp中的不必要部分   修改一些功能

- 离线登录功能 与 账户管理页面
- 自定义背景图片及背景模糊选项
- 新的 素雅, 古典黑 主题
- 删除右侧栏中的广告区域 和 左侧的Modrinth Hosting按钮
- 实现Worlds界面并允许更改其为默认界面
