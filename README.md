# Celestial Launcher

一个面向中文用户的 Minecraft 启动器，基于 [Modrinth App](https://github.com/modrinth/modrinth-app) 深度修改。

在保留 Modrinth 生态（一键安装模组、整合包、资源包、光影）的同时，补上了中文用户真正需要的东西：**多版本库管理**、**`.minecraft` 目录直接接管**、**离线登录**、**完整汉化**与**项目介绍翻译**。

**[前往下载最新版本 →](https://github.com/Wemsur/Celestial-Launcher/releases)**

支持 Windows（安装包）、macOS（通用二进制）、Linux（deb / rpm / AppImage）。

---

## 主要特性

### 📚 多版本库

* **同时管理多个版本库**，顶部标签一键切换，支持拖拽排序并记住上次所在的库。

* **直接接管 `.minecraft` 目录**：可以把 PCL2、HMCL 等启动器的现有 `.minecraft` 文件夹注册为一个库，无缝迁移。同样支持在其中安装实例、修改实例设置。

* **「加入库」只是登记**：添加库**不迁移、不重命名、不移动**任何文件。

* **扫描式实例管理**：实例数据存在各自目录的 JSON 文件里，而不是数据库。

  * 重命名文件夹、复制粘贴都不会丢数据，复制一份就是一个新实例。
  * 即使清空应用数据，实例也能被重新扫描出来。

* 不允许删除最后一个库；库路径是实例身份的来源，因此只读。

### 🌐 中文与本地化

* **完整汉化**，覆盖设置、实例管理、内容安装等主要界面。

* **项目介绍翻译**：浏览页与项目页可一键把作者写的标题与简介翻译成启动器语言。

  * 四个免费服务，均无需自备 API Key：Tencent TranSmart（默认）、Microsoft（Edge / Bing）、Google Translate、MyMemory。
  * 默认的 TranSmart 是唯一国内可直连的选项；某个服务不可用时可随时切换。
  * 可设置进入浏览页时自动开启；译文缓存 7 天，同一段文字只翻译一次。

### 🔍 浏览与安装

* **分屏浏览**：左侧保留搜索结果、右侧打开项目详情，切换项目时筛选条件与滚动位置全部保留。开关状态会被记住。

* **安装到指定实例**：安装模组、资源包、光影、数据包时列出全部实例并标注版本兼容性与是否已安装。

* 创建实例时必须选择版本库，默认预选当前所在的库。

### 👤 账户

* **离线登录**，离线账户拥有多彩头像。

* 独立的**账户管理页面**，可在侧边栏或该页面添加正版 / 离线账户。

* 未登录 Modrinth 账户时，皮肤页面同样可以使用。

### 🎨 外观

* **自定义背景图片**与背景模糊开关。

* **自定义主题色**（色相滑块）。

* 内置主题：自定义深色、自定义浅色、OLED、复古、素雅、古典黑，以及跟随系统。

* **实例卡片图标底纹**：卡片背景使用该实例图标的高度模糊版本，无图标时使用与图标占位一致的生成色。

* **图标编辑器**：丰富的颜色与图标组合，`.minecraft` 格式实例同样支持设置图标。

* 半透明与光感边缘等细节打磨，右侧栏无广告位。

### ⚡ 性能

* 打开实例页面不再等待内容加载完成——框架、标题、启动按钮立即出现，内容列表随后填充。

* 内容列表采用**增量哈希**（大小与修改时间未变则复用已记录的哈希）、**多线程流式哈希**，并缓存解析结果，第二次打开无需访问数据库和网络。

* 消除了同一次打开中对文件的重复哈希，更新检查移出首屏路径。

### 🔄 其他

* **应用内自动更新**：启动时检测并下载，下次重启时应用。

* **从 Modrinth App 导入数据**：首次启动可检测并选择性导入原有数据。

## 从源码构建

需要 Node.js ≥ 24.15、pnpm 10.33+、Rust 稳定版工具链，以及 [Tauri 2 的系统依赖](https://v2.tauri.app/start/prerequisites/)（Linux 还需 `libwebkit2gtk-4.1-dev`、`libayatana-appindicator3-dev`、`librsvg2-dev`）。

```bash
pnpm install
pnpm app:dev        # 开发模式
```

打包当前平台的安装包：

```bash
bash build-release.sh
```

Tauri 无法跨平台交叉编译，因此该脚本只构建**运行它的那个系统**的产物。三平台一次出齐请使用 `.github/workflows/celestial-release.yml`。

## 注意事项

* 请勿从较新的官方 Modrinth App 降级到本项目的旧版本，可能导致数据不一致。

* macOS 版本未经 Apple 签名公证，首次打开请右键「打开」；Windows 版本未经代码签名，SmartScreen 提示时选择「仍要运行」即可。
